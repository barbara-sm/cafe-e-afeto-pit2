# Checklist de execução dos testes

- [ ] XAMPP Apache e MySQL iniciados.
- [ ] Banco importado sem erros.
- [ ] Cadastro de cliente testado.
- [ ] Login válido e inválido testados.
- [ ] Adição e remoção de produtos testadas.
- [ ] Atualização de quantidades e total testados.
- [ ] Finalização de pedido testada.
- [ ] Pedido aparece em “Meus pedidos”.
- [ ] Acesso de cliente à administração bloqueado.
- [ ] Cadastro de produto como administrador testado.
- [ ] Atualização de status testada.
- [ ] Interface testada em tela pequena.
- [ ] Cinco formulários de colegas preenchidos.
- [ ] Correções aplicadas e evidências capturadas.
- [ ] Vídeo de até cinco minutos gravado.
